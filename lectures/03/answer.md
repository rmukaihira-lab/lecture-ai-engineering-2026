# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：

  第1回の素のLLMは、モデルの知識をもとに回答するため、講座固有の情報について正確に答えられない場合がある。

  第3回のエージェントは、用語集を検索するツールを利用できるため、講座で定義された情報を参照して回答できる。

  実際に「AIE2026の講座の宿題にある『3レベル』とは何ですか？」と質問すると、「3つのレベルのうちどれか1つに取り組めば宿題が完了する」と回答した。ただし、「基礎・実装・発展」という具体的な名称は回答に含まれていなかった。

- `--trace` で見えたツール呼び出し（ツール名と引数）：

  「LoRA と QLoRA の違いは？」という質問で、以下のツールが呼び出された。

  - `search_glossary({'query': 'LoRA'})`
  - `search_glossary({'query': 'QLoRA'})`

  それぞれの用語について用語集が検索され、取得した定義をもとに回答が生成された。

- 1つの質問での LLM 呼び出し回数（`requests`）：

  `requests=2`

  なお、ツール呼び出し回数は `tool_calls=2` だった。

- 追加したツールと、docstring に書いた説明：

  `app/tools.py` に `make_quiz(lecture: int) -> str` を追加した。

  このツールは、指定した回の用語集からランダムに1つの用語を選び、確認問題と答えをJSON形式で返す。

  docstringには「指定した回の用語集から確認問題を1問作り、問題と答えを返す」と記載した。また、「第2回の確認問題を出して」など、講座の復習問題を求められたときに使うことも説明した。

  `app/agent.py` に `agent.tool_plain(tools.make_quiz)` を追加して登録した。

  動作確認では、`make_quiz({'lecture': 2})` が呼び出され、「ランク（LoRAのr）」についての確認問題が生成された。

  `uv run pytest -q` の結果は `11 passed` で、すべてのテストに合格した。

## 宿題

- 取り組んだレベル：基礎

  変更前と変更後で同じ「LoRA と QLoRA の違いは？」という質問を `--trace` 付きで実行し、ツール呼び出しと回答内容を比較した。

  - `requests=2`

  - 回答：LoRAとQLoRAの仕組みの違いを説明できた。

  **変更後**
  - `search_glossary`：2回
  - 検索引数：`LoRA`、`QLoRA`
  - `requests=2`
  - `tool_calls=2`
  - 回答：LoRAとQLoRAの仕組みの違いを説明できた。

- 気づき・疑問：

  指示文を削除すれば検索ツールの使用回数が減ると予想していたが、実際には変化しなかった。

  `search_glossary` のdocstringにも「答える前に使うこと」と書かれているため、ツールの説明文がAIの判断に影響している可能性があると考えた。
